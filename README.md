# transthyretin_fibril

This directory contains Supporting Information files and topology files of all simulations discussed in the article.

TTR-fibril-coordinates: This directory contains (besides this README.txt) four folders (Control, K6V, W6Y, W6I) that contain files with the atomic coordinates (in PDB format) of TTR fibril structures discussed in the article. An additional folder (Parameter Files) contains mdp files of parameter settings for GROMACS simulations.

TTR-fibril-topology: This directory contains (besides this README.txt) four folders (Control, K6V, W6I, W6Y) that contain topology files and ITP files (separated by chain) of the simulations discussed in the article.
