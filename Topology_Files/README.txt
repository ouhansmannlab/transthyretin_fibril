This directory contains (besides this README.txt) four folders (Control, K6V, W6I, W6Y) that contain topology files and ITP files (separated by chain) of the simulations discussed in the article.

Fibril;
This folder contains five sub-directories containing TTR fibril topology files and ITP files (separated by chain) describing the system:

1) Control:
topol.top                                             : topology file describing the system
topol_Protein_chain_A.itp - topol_Protein_chain_J.itp : topology .itp files for individual TTR fibril chains
posre_Protein_chain_A.itp - posre_Protein_chain_J.itp : position restraint .itp files for individual TTR fibril chains

2) K6V:
topol.top                                             : topology file describing the system
topol_Protein_chain_A.itp - topol_Protein_chain_J.itp : topology .itp files for individual TTR fibril chains
posre_Protein_chain_A.itp - posre_Protein_chain_J.itp : position restraint .itp files for individual TTR fibril chains

topol_Protein_chain_K.itp - topol_Protein_chain_O.itp : topology .itp files for individual K6V peptides
posre_Protein_chain_K.itp - posre_Protein_chain_O.itp : position restraint .itp files for individual K6V peptides

3) W6Y:
topol.top                                             : topology file describing the system
topol_Protein_chain_A.itp - topol_Protein_chain_J.itp : topology .itp files for individual TTR fibril chains
posre_Protein_chain_A.itp - posre_Protein_chain_J.itp : position restraint .itp files for individual TTR fibril chains

topol_Protein_chain_K.itp - topol_Protein_chain_O.itp : topology .itp files for individual W6Y peptides
posre_Protein_chain_K.itp - posre_Protein_chain_O.itp : position restraint .itp files for individual W6Y peptides

4) W6I:
topol.top                                             : topology file describing the system
topol_Protein_chain_A.itp - topol_Protein_chain_J.itp : topology .itp files for individual TTR fibril chains
posre_Protein_chain_A.itp - posre_Protein_chain_J.itp : position restraint .itp files for individual TTR fibril chains

topol_Protein_chain_K.itp - topol_Protein_chain_O.itp : topology .itp files for individual W6I peptides
posre_Protein_chain_K.itp - posre_Protein_chain_O.itp : position restraint .itp files for individual W6I peptides
